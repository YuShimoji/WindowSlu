# WindowSlu

作業の邪魔にならない、直感的なウィンドウ管理ユーティリティ。

## 概要

`WindowSlu` は、Windows上の任意のウィンドウの透明度を、ホットキーやマウススライダーで手軽に調整できるデスクトップアプリケーションです。v2.0では、グループ化・プリセット・連動ドラッグなどの高度な機能が追加されました。

*   **直感的なウィンドウ操作**: ホットキーやスライダーでリアルタイムに透明度調整
*   **最前面表示 (Always on Top)**: 重要なウィンドウを常に他のウィンドウより手前に表示
*   **クリックスルー**: ウィンドウを操作不能にし、背面のウィンドウを直接クリックできるように
*   **🔥 グループ化機能**: プロセス名ベースの自動グループ化 + 手動グループ作成
*   **🔥 プリセット機能**: サイズ・透明度・位置設定の保存・適用
*   **🔥 カスケード配置**: グループ内ウィンドウの整列配置
*   **🔥 連動ドラッグ**: グループ内ウィンドウの同時移動
*   **🔥 一括操作**: 全ウィンドウへのまとめての透明度適用

集中したい作業がある時、リファレンスを常に表示しておきたい時など、あなたのデスクトップ作業の効率を向上させます。

## 使い方

1.  **実行ファイルの入手**:
    *   リリースページから最新の `WindowSlu.exe` をダウンロードします。
    *   (または、このリポジトリをクローンしてビルドする場合、 `WindowSlu/bin/Release/net10.0-windows/win-x64/publish/` ディレクトリ内に生成されます)
2.  **起動**:
    *   `WindowSlu.exe` をダブルクリックして実行します。
3.  **基本操作**:
    *   Windowsタブで操作したいウィンドウを選択します。
    *   スライダーを動かして透明度を変更します。
    *   ホットキー（`Alt` + `Up`/`Down`など）でアクティブなウィンドウを直接操作します。

### 🔥 新機能の使い方

#### グループ化機能
- **自動グループ化**: 同じプロセス名のウィンドウが自動でグループ化されます
- **手動グループ作成**: Windowsタブの「Group name」に名前を入力し「New Group」で作成します。ウィンドウを選択中なら、そのウィンドウが追加されます
- **編集・保存**: 手動グループを選択してRename/Delete Groupで編集できます。所属変更は自動保存され、再起動後も復元されます。
- **グループ展開**: グループ名の左にある三角アイコンで折りたたみ/展開

#### プリセット機能
- **Presetsタブ**を開いてプリセットを作成・管理します
- **Name**: プリセット名を入力
- **Size**: ウィンドウサイズを指定 (WxH)
- **Opacity**: 透明度を指定 (0-100%)
- **Always on Top**: 最前面表示のオン/オフ
- **Cascade**: カスケード配置の設定
- **Captureボタン**: Windowsタブで選択したウィンドウ/グループの現在設定をプリセットにします
- **Applyボタン**: 選択したグループ/ウィンドウのうち、Process/Group条件にも一致する対象に適用します。未選択なら条件に一致する全対象へ適用します
- **GroupのClear**: グループ条件を解除します
- **Save Presets**: プリセットと手動グループを保存します
- **適用前の確認**: Presets上部に選択対象・Process/Group条件・一致件数を表示します。プリセット未選択のApplyは選択を案内します。
- **Delete / Undo**: プリセット・レイアウトの削除後、対象名付きUndoで保存先まで復帰できます。連続削除は新しい削除から順に戻します。Undoは現在のアプリセッション中に利用でき、復帰した項目は再起動後も残ります。保存失敗時は項目を削除前へ戻し、失敗を表示します。

#### カスケード配置
- グループヘッダーの「▣」ボタンをクリック
- グループ内のウィンドウが重なりながら整列配置されます
- 方向とオフセットはPresetsタブで設定可能

#### 上下・左右の分割配置

- Windowsタブで2枚以上のグループ、またはそのグループに属するウィンドウを選択します。
- グループ編集欄の下の **Side by Side** で左右の等幅配置、**Stacked** で上下の等高配置を行います。3枚以上にも対応します。
- 先頭ウィンドウが現在あるモニターの作業領域を使います。タスクバー領域を避け、端数ピクセルも隙間なく割り当てます。
- 未選択・1枚だけの場合はボタンが無効です。選択外のグループを動かす操作にはなりません。
- 最大化・最小化は通常状態へ戻して配置します。透明度・最前面・クリックスルーの設定は変更しません。
- 連動ドラッグが有効でも配置中は追従を一時抑止し、終了後は元の設定で利用できます。
- アプリの最小サイズ制限などで指定領域へ収まらなかった場合は、実際の位置・サイズと失敗件数を表示します。詳細はステータスにマウスを置いて確認できます。
- 配置後は既存のLayoutsタブからCaptureして保存できます。

#### 連動ドラッグ
- グループヘッダーの「🔗」ボタンでグループの連動ドラッグを有効化
- グループ内のウィンドウをドラッグすると、他のウィンドウも連動して移動します
- 相対位置が維持されます

#### 一括操作
- **Opacity / Apply**: 表示中の値を、近くに表示した対象名・件数へ適用します。単体を選んだ場合はそのウィンドウだけ、グループ選択時はそのグループが対象です。未選択では適用されません。
- **All windows**: チェックすると管理中の全ウィンドウを対象にします。検索フィルターとは独立して全件が対象です。
- **All 100%**: 選択やAll windowsのチェック状態に関係なく、管理中の全ウィンドウを100%に戻します。
- **検索からの操作**: 検索結果を選ぶと、下段の対応グループが展開され、そのウィンドウの操作行が見える位置へ移動します。検索語と入力フォーカスを保持します。
- **サイズスライダー**: マウス操作に加え、フォーカスして矢印キーで1pxずつ調整できます。下部に実サイズまたは失敗を表示します。

#### 🆕 グループ一括制御
- **グループ透明度スライダー**: グループヘッダーのOpacityスライダーでグループ内全ウィンドウの透明度を一括変更
- **グループサイズ設定**: グループヘッダーでサイズ（幅×高さ）を入力し、Applyボタンでグループ内全ウィンドウに適用

#### 🆕 ドラッグ&ドロップ
- **ウィンドウの移動**: ウィンドウをドラッグして別のグループにドロップすると、そのグループに移動します
- **簡単なグループ編集**: 手動でウィンドウのグループ割り当てを変更可能

## こだわった点・苦労した点

### Windows API との連携

ウィンドウの透明度や表示順序、クリックスルーといったOSレベルの挙動を制御するため、`SetWindowLong` や `SetLayeredWindowAttributes` などのWin32 APIを直接呼び出しています。些細なパラメータの違いで予期せぬエラー（特に `Win32Error: 87`）を引き起こすことがあり、安定した動作を実現するために多くの試行錯誤を重ねました。

### MVVMアーキテクチャへのリファクタリング

プロジェクト初期は、UIのイベント処理とビジネスロジックが密結合しており、機能追加やデバッグが困難な状態でした。
開発の過程で、UI (View)・状態管理 (ViewModel)・ビジネスロジック (Model/Service) の責務を分離するMVVMアーキテクチャへリファクタリングを行いました。これにより、コードの見通しが良くなり、リグレッション（バグの再発）が起きにくい、保守性の高い構造へと改善しました。

### 🔥 高度な機能の実装

#### グループ化・プリセット・カスケード配置
ウィンドウの動的なグループ化と設定の永続化を実現するため、JSONベースの設定保存とTreeViewによる階層表示を実装しました。マルチモニター対応も考慮しています。

#### 連動ドラッグの実装
WinEventHookを使用したシステムレベルのウィンドウ移動検知を実装。デバウンス処理とスレッドセーフな設計により、安定した連動動作を実現しました。

## 保存・復元の注意

- JSON設定は `%APPDATA%/WindowSlu/` に保存します。置換保存時に前の内容を `.bak` に残し、破損した読み込み元は `.corrupt-*` として退避します。保存失敗はステータスへ表示します。
- 手動グループは実行中はウィンドウハンドルを追跡し、再起動後はプロセス名とタイトルで照合します。閉じたメンバーも保存します。再起動前後でタイトルが変わった場合は、D&Dで再割り当てしてください。
- 自動グループのIDはプロセス名から決まるため再起動後も維持します。旧版で保存したランダムな自動グループIDは推測で置き換えません。対象が見つからない旧プリセットはGroupを選び直すかClearで解除し、保存してください。
- レイアウト復元は同じウィンドウへ複数項目を適用しません。候補を一意に決められない項目はスキップし、失敗・未一致・曖昧の件数を表示します。ステータスにマウスを置くと詳細を確認できます。
- 保存したモニターが無い場合は、現在の作業領域内へ位置とサイズを補正します。
- Ctrl+MouseWheelはSettingsで無効にできます。操作方法はHelpタブを参照してください。
